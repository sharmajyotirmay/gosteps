## Topic: 1-D dynamic programming
id: t27-dp-1d
days: 4
tags: dynamic-programming

### pattern
Four questions:
1. **State:** what does `dp[i]` mean?
2. **Transition:** how is it built from smaller states?
3. **Base cases.**
4. **Order:** compute states before they're needed.

Write the top-down memoized version first if that helps, then convert it to bottom-up.

```go
func rob(nums []int) int {
    prev, cur := 0, 0 // dp[i-2], dp[i-1]
    for _, n := range nums {
        prev, cur = cur, max(cur, prev+n) // skip i, or take i + dp[i-2]
    }
    return cur
}
```

When `dp[i]` depends only on the last few states, keep rolling variables instead of an array, for O(1) space.

### cards
Q: What are the four steps of designing a DP?
A: Define the state, write the transition, set the base cases, and pick an evaluation order where dependencies are computed first.
Q: How does House Robber II (circular) reduce to House Robber?
A: Run the linear version twice, once excluding the first house and once excluding the last, and take the maximum.
Q: Why does Maximum Product Subarray track both a max and a min?
A: A negative number turns the smallest product into the largest, so you need both extremes at every step.

## Topic: Knapsack and coin change
id: t28-knapsack
days: 3
tags: dynamic-programming

### pattern
**0/1 knapsack** (each item used at most once): loop capacity **downwards**, so an item isn't reused within the same pass. **Unbounded** (items reusable): loop capacity **upwards**.

```go
func coinChange(coins []int, amount int) int {
    dp := make([]int, amount+1) // dp[a] = fewest coins for amount a
    for a := 1; a <= amount; a++ {
        dp[a] = math.MaxInt32
        for _, c := range coins {
            if c <= a && dp[a-c]+1 < dp[a] {
                dp[a] = dp[a-c] + 1
            }
        }
    }
    if dp[amount] == math.MaxInt32 {
        return -1
    }
    return dp[amount]
}
```

To count combinations rather than permutations (Coin Change II), loop over **coins in the outer loop**.

### cards
Q: In a 1-D knapsack array, why loop capacity downwards for 0/1 items?
A: Going downwards, `dp[c-w]` still holds the previous item's row, so each item is counted at most once.
Q: Combinations vs permutations in coin counting: what changes?
A: Coins in the outer loop counts combinations (order ignored). Amount in the outer loop counts permutations (Combination Sum IV).
Q: How does Partition Equal Subset Sum become a knapsack problem?
A: Ask whether some subset sums to `total/2`, which is a boolean 0/1 knapsack over the items.

## Topic: Sequence DP: LIS, LCS, and edit distance
id: t29-sequence-dp
days: 3
tags: dynamic-programming, string

### pattern
Two-sequence problems use `dp[i][j]` over prefixes `a[:i]` and `b[:j]`:

```go
func longestCommonSubsequence(a, b string) int {
    dp := make([][]int, len(a)+1)
    for i := range dp {
        dp[i] = make([]int, len(b)+1)
    }
    for i := 1; i <= len(a); i++ {
        for j := 1; j <= len(b); j++ {
            if a[i-1] == b[j-1] {
                dp[i][j] = dp[i-1][j-1] + 1
            } else {
                dp[i][j] = max(dp[i-1][j], dp[i][j-1])
            }
        }
    }
    return dp[len(a)][len(b)]
}
```

LIS in O(n log n): keep `tails[k]` = the smallest tail of an increasing subsequence of length k+1, and binary search where each number goes (`sort.SearchInts`).

### cards
Q: What does `dp[i][j]` mean in LCS?
A: The length of the LCS of the prefixes `a[:i]` and `b[:j]`.
Q: State the edit distance recurrence.
A: If the characters match, `dp[i][j] = dp[i-1][j-1]`. Otherwise `1 + min(insert dp[i][j-1], delete dp[i-1][j], replace dp[i-1][j-1])`.
Q: How does O(n log n) LIS work?
A: `tails[k]` stores the smallest possible tail of an increasing subsequence of length k+1. Each number replaces the first tail ≥ it (binary search), or extends the list.
